# 零跑汽车远程控制 APP - PWA 版本

## 一键部署

[![Deploy to Netlify](https://www.netlify.com/img/deploy/netlify-button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/2754441547/leapmotor-app)

点击上方按钮，直接部署到 Netlify（免费，无需服务器）。

## 功能

- 远程控制零跑汽车
- PWA 支持，可安装到手机桌面
- 离线可用

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 技术栈

- HTML5 + CSS3 + JavaScript
- Service Worker (离线缓存)
- Web App Manifest (PWA)
